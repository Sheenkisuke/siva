Para probar el reconocimiento facial:
1. Coloque aquí una foto de prueba que cumpla los requisitos (336x448 px, fondo blanco, formato JPG o PNG)
2. Inicie sesión con cualquier usuario de prueba
3. Vaya a Renovación de Cédula > Verificar y Continuar
4. Suba la foto de prueba
5. El sistema validará los requisitos y realizará la comparación facial

Nota: Como los usuarios de prueba tienen fotos placeholder, la comparación facial usará el modo de simulación. Para probar la IA real, reemplace la foto del usuario en static/fotos/ con una foto real y suba una foto similar.
